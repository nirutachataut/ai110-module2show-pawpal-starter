# PawPal+ (Module 2 Project)

You are building **PawPal+**, a Streamlit app that helps a pet owner plan care tasks for their pet.

## Scenario

A busy pet owner needs help staying consistent with pet care. They want an assistant that can:

- Track pet care tasks (walks, feeding, meds, enrichment, grooming, etc.)
- Consider constraints (time available, priority, owner preferences)
- Produce a daily plan and explain why it chose that plan

Your job is to design the system first (UML), then implement the logic in Python, then connect it to the Streamlit UI.

## What you will build

Your final app should:

- Let a user enter basic owner + pet info
- Let a user add/edit tasks (duration + priority at minimum)
- Generate a daily schedule/plan based on constraints and priorities
- Display the plan clearly (and ideally explain the reasoning)
- Include tests for the most important scheduling behaviors

## Implementation Summary

`Owner` stores the owner's information, availability, preferences, and pets. `Pet` stores its name, species, and care tasks. `Task` represents a care activity with a duration, priority, frequency, and completion status. `Scheduler` creates a daily plan from the owner's tasks.

`Owner.get_all_tasks()` gathers tasks from every pet so the Scheduler can consider them together. The Scheduler sorts tasks by priority and adds tasks that fit within the owner's available time. `main.py` demonstrates this by creating pets and tasks, generating a daily plan, and printing the schedule and explanation.

## 📐 Smarter Scheduling

The backend includes these scheduling features:

| Feature | Method(s) | Notes |
|---------|-----------|-------|
| Sorting | `Scheduler.sort_by_time()` and `Scheduler.sort_tasks()` | Sorts by scheduled time (untimed tasks last) or by descending priority. |
| Filtering | `Owner.filter_tasks()` | Filters all owner tasks by optional pet name and completed/pending status. |
| Recurring tasks | `Pet.complete_task()` | Completing a daily or weekly task adds one pending occurrence due the next day or week. Non-recurring tasks do not repeat; an already-completed task is not duplicated. |
| Conflict detection | `Scheduler.detect_conflicts()` | Returns warnings for overlapping pending tasks on the same date. Tasks with invalid or missing scheduling details are ignored. |
